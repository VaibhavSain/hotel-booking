# 🏨 Hotel Booking Web App

A modern and responsive **Hotel Booking Application** built using **React.js** and **Tailwind CSS**.
This project allows users to browse, filter, and book hotels through a sleek and interactive interface.

🔗 **Live Demo:** [https://vaibhavsain.github.io/hotel-booking/](https://vaibhavsain.github.io/hotel-booking/)

---

## 🚀 Features

* 🔍 **Search & Filter Hotels** — Filter by price, location, and rating
* 🏖️ **Responsive Design** — Works seamlessly on all screen sizes
* ⚡ **Dynamic UI** — Powered by React hooks and component-based architecture
* 📋 **Booking Simulation** — Mimics the hotel reservation process
* 🧭 **Smooth Navigation** — Implemented with React Router
* 🎨 **Tailwind CSS Styling** — Clean, modern, and customizable design

## ⚙️ Installation & Setup

To run this project locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/vaibhavsain/hotel-booking.git
   cd hotel-booking
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm start
   ```

4. Open your browser and go to **[http://localhost:3000](http://localhost:3000)**

---

## 📦 Deployment

This project is deployed using **GitHub Pages**.
To deploy your own version:

```bash
npm run build
npm run deploy
```
